# Interactive Resume Builder

A client-side TypeScript application that enables job seekers to generate, edit, and export professional, printable resumes dynamically.

## 📄 Features
- **Live Preview**: Real-time updates as you type your personal, educational, and work history.
- **Customizable Layout**: Sections for skills, projects, certifications, and experience.
- **Print & PDF Export**: CSS print stylesheets optimized for clean single- or multi-page PDF generation.

## 🛠️ Tech Stack
- **Frontend**: TypeScript, HTML5, CSS3
